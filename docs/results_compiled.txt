---- INTERPRETATION ----

  Binary F1 ~0.32
    The model detects some mistakes but misses many and also fires false
    positives. Acceptable for a frozen zero-shot VLM with no task training.

  Macro F1 ~0.17–0.20
    Near-random class prediction. Model rarely identifies whether the mistake
    is wrong_action vs wrong_object. Class label quality is very weak.

  AUC-ROC ~0.60
    Slightly above random (0.5). The raw confidence scores do rank mistake
    windows above clean windows, but not reliably.

  ECE ~0.77
    Very high. Means the model's stated confidence is badly miscalibrated.
    When it says 0.8 confidence, it is often wrong.
    This must be addressed in Phase 4 (LoRA with calibration loss).

  Adaptive == Fixed (known bug)
    Both thresholds produce identical numbers because:
    1. Threshold params were not yet fitted (using default bias=-0.5).
    2. The per-window τ was not saving prediction records, so
       03b_fit_threshold.py could not have been run.
    Fix applied (code updated): τ now computed per window with history,
    and preds_online.json will be saved on next run.

  Online ≈ Offline F1 (suspicious)
    Online and offline F1 are nearly identical (0.317 vs 0.324).
    Offline should be higher since it has full video context.
    Possible cause: step index advances too aggressively in online mode,
    overriding the causal constraint. Needs investigation.
