Plan — Procedural Graph-Guided + Uncertainty-Aware VLM Mistake Detection (EgoOops)
=================================================================================

CONTEXT
-------
Research project on procedural mistake detection in egocentric video.
Target: EMNLP 2026 (ARR rolling), NAACL 2026 fallback.
Empty repo as of 2026-05-12. Full pipeline: data → procedural graph → VLM reasoning → uncertainty-aware decision → eval.

Two contributions:
  A. Procedural Graph-Guided VLM Reasoning
     - LLM-generated graph: nodes = step/objects/actions/states, edges = temporal deps
     - VLM observes clip-by-clip, computes relevance score vs graph, flags deviation
  B. Uncertainty-Aware Adaptive Threshold
     - VLM self-reports uncertainty (occlusion, ambiguity, multi-variant step, short window)
     - τ adapts per task: complexity, valid variants, uncertainty, graph confidence, history

Novelty over prior work:
  - MistSense/PREGO/MoniTor: binary detection → we do multiclass + start-time localization
  - ASK-HINT: generic prompts → we add procedural graph grounding
  - Framing: language-structured prior for video reasoning (fits NLP venues)

SCOPE (LOCKED)
--------------
Dataset:          EgoOops (ICCVW 2025)
VLM:              Qwen2.5-VL-7B, local, single A100/H100 80GB
Graph source:     LLM-generated from task descriptions (auto, cached JSON)
Adaptation:       Two-stage — zero-shot baseline first, then LoRA fine-tune
Eval mode:        Both online (causal) and offline (full video), reported side by side
Venue:            ARR → EMNLP 2026

ARCHITECTURE
------------
EgoOops video ──► Frame/clip sampler
                        │
                        ▼
Task text ──► LLM Procedural Graph Builder (offline, cached)
                        │
                        ▼
              Graph-conditioned prompt (current step, valid next, expected objects/states)
                        │
                        ▼
Clip frames ──► Qwen2.5-VL-7B (frozen → LoRA)
                → {step_id, deviation_logit, uncertainty, rationale, expected_vs_observed}
                        │
                        ▼
              Uncertainty-aware decision head (adaptive τ)
                        │
                        ▼
    Per-frame: mistake label + start-of-deviation timestamp + class + rationale

PHASED EXECUTION (10 weeks → EMNLP 2026 ARR)
---------------------------------------------
Phase 0 — Setup (week 1)
  - pyproject.toml with torch, transformers>=4.49, qwen-vl-utils, peft, accelerate,
    bitsandbytes, decord, pydantic, hydra-core, wandb, scikit-learn, outlines
  - configs/base.yaml, egoops.yaml
  - src/vmd/data/egoops.py loader
  - src/vmd/eval/metrics.py + tests/test_metrics.py (golden tests on synthetic labels)

Phase 1 — Procedural Graph Builder (week 2)
  - graph/schema.py: pydantic Step, Object, Action, State, Edge(kind∈{after,requires,produces})
  - graph/builder.py: prompt → LLM API → JSON → cache
  - graph/validator.py: DAG check, no dangling refs, vocab grounding
  - Build all EgoOops task graphs → data/graphs/*.json
  - tests/test_graph_schema.py: round-trip load, DAG validity

Phase 2 — Zero-shot VLM baseline (week 3)
  - vlm/qwen25vl.py: HF load, qwen-vl-utils frame packing, JSON structured output
  - vlm/prompts/reason.txt: graph-conditioned template
  - vlm/uncertainty.py: verbalized confidence + token logprob on "deviation" token
  - Run online + offline eval on EgoOops val → lock baseline numbers

Phase 3 — Uncertainty-Aware Threshold (week 4)
  - decision/threshold.py: τ formula, params fit on val set
  - decision/postprocess.py: median/HMM smoothing, start-of-deviation localization
  - Ablation: adaptive τ vs fixed τ

Phase 4 — LoRA fine-tune (weeks 5-6)
  - train/lora_train.py: LoRA rank 16-64, bf16, gradient checkpointing
  - train/losses.py: CE + ECE-penalty
  - ~24-48h A100 80GB
  - Re-run full eval with adapters

Phase 5 — Baselines + ablations (week 7)
  - Reproduce MoniTor on EgoOops (open source baseline)
  - Cite-only: MistSense, PREGO, ASK-HINT
  - Ablation table: (i) no graph, (ii) graph+fixed τ, (iii) graph+adaptive τ, (iv) +LoRA

Phase 6 — Writing + figures (weeks 8-10)
  - Architecture figure, qualitative examples (3 success + 2 failure)
  - Tables: main results, ablations, calibration, per-task
  - ARR submission

METRICS
-------
- Mistake F1 (binary), macro-F1 (multiclass)
- Edit Distance (ED) over predicted vs gt sequence
- AUC-ROC per-frame deviation score
- Start-of-deviation MAE (seconds, offline) / lag-to-detect (online)
- EDS (Early Detection Score)
- ECE, Brier (calibration)

RISKS + MITIGATIONS
-------------------
- Noisy LLM graphs → DAG validator + 10% manual audit
- Qwen JSON instability → outlines constrained decoding + regex fallback
- LoRA hurts calibration → joint ECE loss term; report pre/post ECE
- EgoOops too small → EgoPER cross-dataset eval (stretch goal, week 7)
- Long-clip context → frame sub-sampling + sliding KV cache
