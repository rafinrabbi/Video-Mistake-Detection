# MistSense — Minimal Reproduction

Reference: Patsch, Wu, Zakour, Salihu, Steinbach.
"MistSense: Versatile Online Detection of Procedural and Execution Mistakes," ICCV 2025.
[PDF](https://openaccess.thecvf.com/content/ICCV2025/papers/Patsch_MistSense_Versatile_Online_Detection_of_Procedural_and_Execution_Mistakes_ICCV_2025_paper.pdf)

This directory contains a minimal, citation-anchored PyTorch reproduction of the MistSense architecture. Generated by `paper2code` from the published CVF PDF. No official author code was available at generation time — every ambiguity is flagged in `REPRODUCTION_NOTES.md`.

## What this implements

- **§3.1** Dual-stream Q-Former architecture: ViT-L → Video Q-Former + Mediapipe hand-pose → TCN encoder → Hand Q-Former → summed fusion → per-query binary mistake logits.
- **§3.2** Sigmoid gating + linear projection from Video Q-Former to Llama-2-7B embedding space, threshold-routed for error explanation.
- **§3.3** Three-stage training schedule with weighted BCE → CE on explanation tokens → LoRA-finetuned LLM.
- **§4.6** AdamW, lr 3e-5 (main) / 2.5e-2 (hand encoder), wd 5e-3, cosine + linear warmup from 1e-6, 12 epochs, dataset-specific batch sizes and class weights.

## What this does NOT do

- Download or extract from Epic-tent / HoloAssist — both datasets are gated. Users precompute per-clip features and place them in `data_root/<clip_id>/{visual.npy, hand.npy, labels.npy, explanation.txt}`.
- Fetch ViT-L / BLIP-2 Q-Former / Llama-2-7B weights — load them externally via `transformers`. The scaffold runs end-to-end on the trainable subnet only (Q-Formers, hand encoder, mistake head, LLM projection).
- Reimplement BLEU / ROUGEL / CIDEr — use `pycocoevalcap`.

See `REPRODUCTION_NOTES.md` for the full ambiguity audit.

## Quick start (sanity check, no real data)

```python
import torch
from src.model import MistSense, ModelConfig

cfg = ModelConfig()
m = MistSense(cfg)
B, T, V, M, C = 2, cfg.segment_length, cfg.num_joints, cfg.num_hands, cfg.coord_dim
visual = torch.randn(B, T, cfg.d_visual)
hand = torch.randn(B, C, T, V, M)
out = m(visual, hand)
print(out["logits"].shape)   # (2, 32)
print(out["gate"].shape)     # (2,)
```
